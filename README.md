# دوائي — تذكير الأدوية

نموذج أولي عربي (RTL) بثلاث شاشات، بألوان الأخضر والرمادي:
1. تعريف بالتطبيق وبيانات دخول تجريبية.
2. رقم المستفيد، رقم جهة الطوارئ، وبريد التقرير.
3. إضافة الأدوية ومواعيدها، تسجيل الجرعات، إنشاء تقرير بالبريد، وفتح الاتصال يدويًا.

## تشغيل المشروع
- افتح `index.html` في المتصفح للتجربة.
- لرفعه على GitHub: أنشئ مستودعًا جديدًا وارفع الملفات الأربعة إلى المستوى الرئيسي.
- لتشغيله كرابط: من إعدادات المستودع افتح **Settings → Pages**، واختر فرع `main` والمجلد `/ (root)` ثم احفظ. انتظر حتى يظهر رابط GitHub Pages.
- استخدم HTTPS لتفعيل إشعارات المتصفح، واسمح بالإشعارات عند الطلب.

## حدود مهمة في هذه النسخة
- هذا نموذج واجهة أمامية فقط، وليس نظامًا طبيًا أو تسجيل دخول آمنًا.
- البيانات محفوظة في `localStorage` داخل المتصفح والجهاز نفسه؛ لا تتم مزامنتها مع أفراد الأسرة.
- التذكيرات تعمل عندما تكون صفحة التطبيق مفتوحة فقط. قد تختلف الإشعارات حسب المتصفح وإعدادات الجهاز.
- لا يمكن لصفحة ويب مستضافة على GitHub Pages إجراء مكالمة طوارئ تلقائية موثوقة أو تجاوز قفل الهاتف. زر الاتصال يفتح تطبيق الهاتف ويحتاج المستخدم إلى تأكيد المكالمة.
- زر التقرير يفتح تطبيق البريد برسالة جاهزة، ولا يرسلها تلقائيًا.
- لا تعتمد على هذا النموذج وحده في إدارة الأدوية أو الطوارئ. راجع الطبيب/الصيدلي بشأن الجرعات، واختبره مع مرافق قبل أي استخدام عملي.

## الملفات
- `index.html` — الشاشات والمحتوى.
- `style.css` — التصميم والألوان والتوافق مع الهاتف.
- `script.js` — التفاعلات والحفظ المحلي والإشعارات.
